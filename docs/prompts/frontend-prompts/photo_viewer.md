# Photo Viewer

**Description:** This document contains all of the codes that are used with **React Zoom Pan Pinch** API.

**Source:** https://bettertyped.github.io/react-zoom-pan-pinch/

---

## Installation

```bash
npm install react-zoom-pan-pinch
```

---

## Introduction

### Quick Start

The simplest setup — wrap any content with `TransformWrapper` and `TransformComponent`:

```jsx
import { TransformWrapper, TransformComponent } from "react-zoom-pan-pinch";

const App = () => (
  <TransformWrapper>
    <TransformComponent>
      <img src="image.jpg" alt="Zoomable" />
    </TransformComponent>
  </TransformWrapper>
);
```

---

### With Controls (Render Props)

Access zoom/pan handlers through render props.

```jsx
import { TransformWrapper, TransformComponent } from "react-zoom-pan-pinch";

const App = () => (
  <TransformWrapper
    initialScale={1}
    initialPositionX={200}
    initialPositionY={100}
  >
    {({ zoomIn, zoomOut, resetTransform }) => (
      <>
        <div className="tools">
          <button onClick={() => zoomIn()}>+</button>
          <button onClick={() => zoomOut()}>-</button>
          <button onClick={() => resetTransform()}>x</button>
        </div>
        <TransformComponent>
          <img src="image.jpg" alt="Zoomable" />
        </TransformComponent>
      </>
    )}
  </TransformWrapper>
);
```

---

### With Ref and `zoomToElement`

Use a ref for imperative access outside of render props:

```jsx
import { useRef } from "react";
import {
  TransformWrapper,
  TransformComponent,
  ReactZoomPanPinchRef,
} from "react-zoom-pan-pinch";

const App = () => {
  const ref = (useRef < ReactZoomPanPinchRef) | (null > null);

  const focusImage = () => {
    ref.current?.zoomToElement("imgExample");
  };

  return (
    <TransformWrapper ref={ref}>
      {({ zoomIn, zoomOut, resetTransform }) => (
        <>
          <button onClick={() => zoomIn()}>+</button>
          <button onClick={() => zoomOut()}>-</button>
          <button onClick={() => resetTransform()}>x</button>
          <TransformComponent>
            <img src="image.jpg" alt="Zoomable" id="imgExample" />
            <div onClick={focusImage}>Focus image</div>
          </TransformComponent>
        </>
      )}
    </TransformWrapper>
  );
};
```

## Handlers

Methods available via **render** **props**, **ref**, or the `useControls` hook. Each handler triggers an animated transition on the transform state.

### `zoomIn({step, animationTime, animationType})`

Function used for zoom in button.

| PARAM           | TYPE                    | DEFAULT   |
| :-------------- | :---------------------- | :-------- |
| `step`          | number                  | `0.5`     |
| `animationTime` | number                  | `300`     |
| `animationType` | keyof typeof animations | `easeOut` |

### `zoomOut({step, animationTime, animationType})`

Function used for zoom out button.

| PARAM           | TYPE                    | DEFAULT   |
| :-------------- | :---------------------- | :-------- |
| `step`          | number                  | `0.5`     |
| `animationTime` | number                  | `300`     |
| `animationType` | keyof typeof animations | `easeOut` |

### `setTransform({x, y, scale, animationTime, animationType})`

Function used for custom transformation animation.

| PARAM           | TYPE                    | DEFAULT   |
| :-------------- | :---------------------- | :-------- |
| `x`             | number                  | -         |
| `y`             | number                  | -         |
| `scale`         | number                  | -         |
| `animationTime` | number                  | `300`     |
| `animationType` | keyof typeof animations | `easeOut` |

### `resetTransform({animationTime, animationType})`

Function used for reset button.

| PARAM           | TYPE                    | DEFAULT   |
| :-------------- | :---------------------- | :-------- |
| `animationTime` | number                  | `200`     |
| `animationType` | keyof typeof animations | `easeOut` |

### `centerView({scale, animationTime, animationType})`

Function used for centering the content component.

| PARAM           | TYPE                    | DEFAULT   |
| :-------------- | :---------------------- | :-------- |
| `scale`         | number                  | undefined |
| `animationTime` | number                  | `200`     |
| `animationType` | keyof typeof animations | `easeOut` |

### `zoomToElement({node, scale, animatioTime, animationType, offsetX, offsetY})`

Zooms and pans so the node(s) fill the viewport. Pass an element, an element id, or an array of them to frame the union of several elements. The second argument is either the target scale or an options object; `minScale`/`maxScale` cap the automatically computed fit scale. Returns a promise that resolves when the animation finishes.

| PARAM           | TYPE                                                                                         | DEFAULT   |
| :-------------- | :------------------------------------------------------------------------------------------- | :-------- |
| `node`          | HTMLElement, string, Array<HTMLElement, string>                                              | -         |
| `scale`         | number, { scale?, minScale?, maxScale?, animationTime?, animationType?, offsetX?, offsetY? } | undefined |
| `animationTime` | number                                                                                       | `600`     |
| `animationType` | keyof typeof animations                                                                      | `easeOut` |
| `offsetX`       | number                                                                                       | `0`       |
| `offsetY`       | number                                                                                       | `0`       |

### `zoomToPoint({scale, clientX, clientY. animationTime, animationType})`

Zooms to `scale` keeping the content point under the given client (viewport) coordinates fixed on screen — the same anchoring a wheel zoom does at the cursor. Use it for click-to-zoom. Returns a promise that resolves when the animation finishes.

| PARAM           | TYPE                    | DEFAULT   |
| :-------------- | :---------------------- | :-------- |
| `scale`         | number                  | -         |
| `clientX`       | number                  | -         |
| `clientY`       | number                  | -         |
| `animationTime` | number                  | `300`     |
| `animationType` | keyof typeof animations | `easeOut` |

### `clientToContent({clientX, clientY})`

Converts client (viewport) coordinates such as `event.clientX/Y` into unscaled content coordinates, independent of the current pan and zoom.

| PARAM     | TYPE   | DEFAULT |
| :-------- | :----- | :------ |
| `clientX` | number | -       |
| `clientY` | number | -       |

### contentToClient({x, y})

Inverse of `clientToContent`: converts unscaled content coordinates into client (viewport) coordinates for the current transform.

| PARAM | TYPE   | DEFAULT |
| :---- | :----- | :------ |
| `x`   | number | -       |
| `y`   | number | -       |

### `fitToView({ options.mode, options.minScale, options.maxScale, options.animationTime, options.animationType })`

Fits the whole content into the viewport (`contain`) or fills the viewport with it (`cover`), centred. Honours the wrapper's `minScale`/`maxScale` — lower `minScale` to let large content shrink. Returns a promise that resolves when the animation finishes. See also the `fitOnInit` prop.

| PARAM                   | TYPE                    | DEFAULT   |
| :---------------------- | :---------------------- | :-------- |
| `options.mode           | 'contain', 'cover'      | 'contain' |
| `options.minScale`      | number                  | undefined |
| `options.maxScale`      | number                  | undefined |
| `options.animationTime` | number                  | `200`     |
| `options.animationType` | keyof typeof animations | easeOut   |

### `panBy({ deltaX, deltaY, animationTime, animationType })`

Pans by a pixel delta (positive x moves the content right), limited to the bounds when `limitToBounds` is on. Backs the keyboard arrows and directional buttons. Returns a promise that resolves when the animation finishes.

| PARAM           | TYPE                    | DEFAULT   |
| :-------------- | :---------------------- | :-------- |
| `deltaX`        | number                  | -         |
| `deltaY`        | number                  | -         |
| `animationTime` | number                  | `200`     |
| `animationType` | keyof typeof animations | `easeOut` |
