# Implementation Plan: Add MUI React Dependencies

**Branch**: `003-add-mui-dependencies` | **Date**: 2026-11-05 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/003-add-mui-dependencies/spec.md`

## Summary

Declare and install the MUI component library in `apps/frontend` so the team can build future interface surfaces with consistent, accessible components, and record the dependency in `docs/tech_stack.md` and `docs/project_setup.md`. The change adds four runtime packages (MUI core, MUI icons, and the two Emotion styling peers), refreshes the frontend lockfile, and documents how MUI coexists with the existing Tailwind CSS system. No existing components are migrated and no application behavior changes.

## Technical Context

**Language/Version**: JavaScript ES modules on Node.js 24.x (minimum 22.12)

**Primary Dependencies**: React 19.2.8, React DOM 19.2.8, Vite 8.3.0, Tailwind CSS 4.3.3; adding `@mui/material` ^9.5.0, `@mui/icons-material` ^9.5.0, `@emotion/react` ^11.14.0, `@emotion/styled` ^11.14.1

**Storage**: N/A

**Testing**: Vitest is configured for the frontend, but the required test tooling packages remain deferred by the maintainer. This dependency-only change adds no tests; verification uses install, build, lint, content verification, and a manual tour smoke test.

**Target Platform**: Modern desktop and mobile browsers with JavaScript and WebGL enabled; minimum supported width 320 CSS pixels.

**Project Type**: Web application (React + Vite frontend, Express backend) following MVC.

**Performance Goals**: Preserve the current interactive panorama experience (target 60 fps) and avoid rendering the component library when existing screens do not use it.

**Constraints**: MUI must coexist with Tailwind CSS 4 without re-enabling Tailwind Preflight or globally resetting the existing design tokens. Added packages must resolve against React 19 with no peer-dependency errors. Existing install, build, lint, and content-verification commands must keep working.

**Scale/Scope**: One frontend workspace dependency update, two documentation files, and the frontend lockfile. Four packages added. No component migration and no backend change.

## Phase 0: Research Summary

See [research.md](./research.md). Key decisions:

- Install `@mui/material`, `@mui/icons-material`, `@emotion/react`, and `@emotion/styled` as runtime dependencies.
- Use MUI 9.x because its peer range includes React 17 through 19, which covers the installed React 19.2.8.
- Rely on Emotion for styling and leave `@mui/material-pigment-css` out; it is an optional peer for the Pigment CSS path.
- Keep Tailwind CSS as the primary styling system for existing surfaces. MUI is additive and must not enable Tailwind Preflight or inject a global CSS baseline into existing screens.
- Verify with install, build, lint, content verification, and a manual tour smoke test.
